Sobre la advertencia de migrar a PKCS12:

	El formato JKS funciona bien y Spring Cloud Config lo soporta sin problema.
	La advertencia es porque JKS es propietario de Oracle, mientras que PKCS12 es estándar y más portable.
	No es obligatorio migrar, pero sí recomendable a futuro (especialmente si vas a desplegar en AWS/EKS o usar integraciones externas).
	Si quieres migrar ahora mismo, el comando es sencillo y no rompe nada:

		keytool -importkeystore -srckeystore keystore.jks -destkeystore keystore.p12 -deststoretype pkcs12

Proceso Simetrico:

	En lugar de generar un par de claves pública/privada (RSA), se crea una sola clave secreta que sirve tanto para cifrar como para descifrar.

	Comando de ejemplo:

		keytool -genseckey -alias mysecret -keyalg AES -keysize 128 -storetype JCEKS -keystore keystore-symmetric.jceks

 
	Detalles:

		-genseckey → genera clave secreta (simétrica).

		-keyalg AES → algoritmo de cifrado simétrico.

		-storetype JCEKS → recomendado para claves secretas (JKS no soporta bien claves simétricas).

		-keysize 128 → tamaño de la clave AES (puede ser 128, 192 o 256 según soporte).

		Alias: mysecret.

Configuración en application.properties:

	encrypt.keyStore.location=classpath:/keystore-symmetric.jceks
	encrypt.keyStore.password=changeit
	encrypt.keyStore.alias=mysecret
